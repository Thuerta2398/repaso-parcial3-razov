# Repaso Parcial 3 · Razonamiento Matemático V

Actividad interactiva para repasar media, mediana, moda, varianza, desviación estándar y coeficiente de variación sin hacer cuentas. Tiene 3 estaciones y una ronda relámpago, dura unos 25 minutos y está hecha para celular o tablet, en vertical u horizontal.

Elaborado por: Dr. T. Huerta

## Publicar en GitHub Pages (una sola vez)

1. Entra a https://github.com y toca **+** → **New repository**.
2. En *Repository name* escribe `repaso-parcial3`, deja **Public** y toca **Create repository**.
3. En la página del repositorio vacío, toca el enlace **uploading an existing file**.
4. Abre esta carpeta (`repaso-parcial3`) en Finder, selecciona **todo su contenido** (`index.html`, `README.md` y las carpetas `css` y `js`) y arrástralo a la página. Arrastra el contenido, no la carpeta.
5. Abajo toca **Commit changes**.
6. Ve a **Settings** → **Pages**. En *Branch* elige `main`, carpeta `/ (root)`, y toca **Save**.
7. Espera de 1 a 2 minutos y recarga esa página. Arriba aparecerá tu enlace:
   `https://TU-USUARIO.github.io/repaso-parcial3/`

## Actualizar después de un cambio

1. En `index.html`, sube el número de `?v=1` a `?v=2` (en las 4 líneas que lo tienen) para que los celulares no usen la versión vieja.
2. En el repositorio: **Add file** → **Upload files**, arrastra los archivos que cambiaron → **Commit changes**. GitHub reemplaza los archivos que tienen el mismo nombre.
3. En 1 o 2 minutos el sitio se actualiza solo.

## Archivos

| Archivo | Contenido |
|---|---|
| `index.html` | Página principal |
| `css/styles.css` | Diseño (claro/oscuro, vertical/horizontal) |
| `js/data.js` | **Todo el contenido:** tarjetas, retos, gráficas y preguntas. Edita aquí para cambiar textos. |
| `js/store.js` | Guardado automático, código de reanudación y código de verificación |
| `js/app.js` | Funcionamiento de las estaciones |

No necesita instalar nada ni conexión a internet una vez cargada.
